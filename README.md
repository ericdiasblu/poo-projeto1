# Lab 1 POO — Gestão de Obras e Empreendimentos

Sistema legado de gerenciamento de obras civis, materiais e equipes.

## Como compilar e executar

```bash
cd src
javac *.java
java Main
```

## Estrutura

| Classe | Responsabilidade declarada |
|--------|---------------------------|
| `GestorObras` | Gerenciador central de obras |
| `Obra` | Dados de uma obra |
| `Material` | Dados de um material |
| `Funcionario` | Dados de um funcionario |
| `Main` | Ponto de entrada e demonstração |

## Problemas conhecidos a investigar

O sistema possui comportamentos inesperados que devem ser identificados e corrigidos pela equipe.

Analise o código com atenção antes de propor qualquer refatoração.
